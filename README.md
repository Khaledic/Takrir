# Takrir - Reports Management System

## Branch: shadcn-primer
**Tech Stack:** React + TypeScript + Tailwind CSS + shadcn/ui + GitHub Primer

### Features
- 🎨 GitHub Dark Theme with green accent (#238636)
- 📊 Reports dashboard with data visualization
- 📈 Charts and analytics
- 📥 Upload and export functionality
- 🎯 Responsive design

### Installation
```bash
npm install
npm run dev
```

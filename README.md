# Takrir - Reports Management System

## Branch: shadcn-tailwind
**Tech Stack:** React + TypeScript + Tailwind CSS (Pure)

### Features
- ✨ Clean, modern design with light theme
- 🎨 GitHub Green accent (#238636)
- 📊 Reports dashboard with data visualization
- 📈 Charts and analytics with Recharts
- 📤 Upload and export functionality
- 🎯 Fully responsive design
- ⚡ Smooth transitions and hover states

### Installation
```bash
npm install
npm run dev
```

### Color Palette (Light Theme)
- Primary Green: `#238636`
- White Background: `#ffffff`
- Light Gray BG: `#f6f8fa`
- Lighter Gray BG: `#eaeef2`
- Border: `#d0d7de`
- Primary Text: `#24292f`
- Secondary Text: `#57606a`

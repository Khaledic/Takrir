# Takrir - Reports Management System

## Branch: tailwind-primer
**Tech Stack:** React + TypeScript + Tailwind CSS + GitHub Primer Design System

### Features
- 🎨 GitHub Primer design system integration
- ✨ Clean, professional GitHub-style UI
- 📊 Reports dashboard with data visualization
- 📈 Charts and analytics with Recharts
- 📤 Upload and export functionality
- 🎯 Fully responsive design
- ⚡ Smooth transitions and interactions
- ♿ Accessible components

### Installation
```bash
npm install
npm run dev
```
